# Decisions

1. **Framework**: Used Next.js App Router for optimal performance.
2. **Styling**: Tailwind CSS configured for navy/red/white brand colors and Noto Sans Devanagari support.
3. **Components**: Lucide-react used for icons. Server components by default. Client components only where interactivity requires it.
4. **Data**: Setup stubs and TODOs for missing data.
5. **Assets**: Reusing existing images from public folder.
