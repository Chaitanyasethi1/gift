# AS Print Gallery

E-commerce platform for AS Print Gallery, a packaging & printing factory in Loni, Ghaziabad.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Tech Stack
- Next.js 14 (App Router)
- Tailwind CSS
- TypeScript
- Lucide React
