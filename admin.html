Supabase Database Not Connected Yet

Hi Admin! Right now this is a static visual dashboard template. To make it dynamic (so you can add/edit products and see real orders), we need to connect it to a free Supabase database. Please follow these steps:

  1. Go to Supabase.com and sign up for a free account.
  2. Create a New Project (name it something like "as-print-gallery").
  3. Go to the SQL Editor on the left sidebar in Supabase, click "New Query", paste this code, and click RUN:
create table products ( id uuid default gen_random_uuid() primary key, title text not null, category text not null, price numeric not null, moq integer not null, image_url text, is_active boolean default true, created_at timestamp with time zone default timezone('utc'::text, now()) not null );

Once done, go to Project Settings -> API and give your developer the Project URL and anon public API key so they can connect the backend!
